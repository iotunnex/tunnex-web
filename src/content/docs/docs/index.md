Tunnex is a self-hosted Zero Trust VPN: WireGuard data plane, SSO, and access
policies on infrastructure you run.

- [CLI](/docs/cli/) — server administration and headless clients.
- [SSO setup](/docs/sso-setup/) — Google and Microsoft Entra ID sign-in.
