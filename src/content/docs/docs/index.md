Tunnex is a self-hosted Zero Trust VPN: WireGuard data plane, SSO, and access
policies on infrastructure you run.

## Where to start

- [Quickstart](/docs/quickstart/) — install the server and connect a device.
- [Architecture](/docs/architecture/) — control plane, gateways, clients, and the
  trust boundary.
- [Desktop client](/docs/desktop-client/) — macOS and Windows apps.
- [CLI](/docs/cli/) — server administration and headless clients.
- [SSO setup](/docs/sso-setup/) — Google and Microsoft Entra sign-in.
